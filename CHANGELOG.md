# Changelog

All notable public releases of Netrin are documented here.

## [0.1.2] - 2026-08-23

Initial public-source release.

- Published the mobile-first route authoring, moderation, download, and
  guidance PWA as a history-free source snapshot.
- Added AGPL-3.0-or-later project licensing, third-party dependency notices,
  and separate ODbL-1.0 attribution for OpenStreetMap-derived path data.
- Required authenticated, phone-confirmed, active accounts for the AMap route
  planning proxy and bound rate limits to user identity plus a trusted proxy
  address.
- Upgraded React Router, PostCSS, and NanoID to patched versions.
- Added CI, CodeQL, Dependabot, Biome linting, DCO enforcement, community
  files, secret scanning gates, and clean-clone verification guidance.
