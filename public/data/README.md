# Bundled path data

`campus-paths.json` contains path geometry derived from OpenStreetMap and is
used only for the optional local snap-to-path feature. Netrin continues to
record raw GPS points when the dataset has no nearby path or when snapping is
disabled.

- Source: [OpenStreetMap](https://www.openstreetmap.org)
- Attribution: © OpenStreetMap contributors
- License: [Open Data Commons Open Database License 1.0](https://opendatacommons.org/licenses/odbl/1-0/)
- Machine-readable metadata: `campus-paths.metadata.json`

The original extraction date and query were not retained in the private
prototype. This provenance limitation is disclosed here; replace the dataset
before release if a reproducible extraction record is required.

The ODbL applies to this dataset independently of Netrin's
AGPL-3.0-or-later source-code license.
